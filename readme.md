# 🛠️ Colección de Utilidades Python - Automatización de Archivos

Colección de scripts en Python para automatizar tareas repetitivas con archivos de Excel, PDF e imágenes. Ideal para trabajo de oficina, organización y limpieza de datos.

Creado por **Rosdel Reyes** | @reyesrosdel83

### 📦 Proyectos Incluidos

| Carpeta | ¿Qué hace? | Librerías clave |
| :--- | :--- | :--- |
| **10 EXCELS A UNO** | Une 10 o más archivos Excel en uno solo. | `pandas`, `openpyxl` |
| **TRABAJO_CON_EXCELS** | Limpieza, filtros y manipulación de datos en Excel. | `pandas` |
| **VARIOS PDFS EN UNO** | Combina múltiples PDFs en un solo documento. | `PyPDF2`, `pymupdf` |
| **JPG_A_PDF** | Convierte imágenes JPG/PNG a PDF. | `Pillow`, `img2pdf` |
| **IMAGENES DUPLICADAS** | Detecta y elimina imágenes duplicadas exactas. | `hashlib`, `Pillow` |
| **BUSCAR DUPLICADOS IMAGEN** | Busca duplicados visuales aunque tengan distinto tamaño/nombre. | `imagehash` |
| **ARCHIVOS PESADOS** | Encuentra los archivos más pesados en una carpeta. | `os`, `pathlib` |
| **ORGANIZAR CARPETAS** | Organiza automáticamente archivos por tipo/fecha/extensión. | `shutil`, `os` |
| **FORMULARIO DE ENTRADA** | Formulario con Tkinter para ingreso de datos. | `tkinter`, `customtkinter` |
| **LLUVIA MATRIX** | Efecto visual lluvia de código al estilo Matrix. | `pygame` / `tkinter` |
